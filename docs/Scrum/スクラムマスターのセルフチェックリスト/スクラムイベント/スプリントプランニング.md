# スプリントプランニングのチェックリスト

タイムボックス：1か月スプリントで最大8時間（2週間なら4時間目安）。

- [ ] タイムボックス内に終わっている（毎回延長していない）
- [ ] Why（なぜこのスプリントに価値があるか）→ What（何をやるか）→ How（どう進めるか）の3トピックが揃っている
- [ ] 休暇・割り込み対応・リファインメントを考慮したキャパシティで計画している
- [ ] 前スプリントの未完了アイテムが「自動で繰り越し」されず、再度優先順位を判断している
- [ ] プランニング終了時点で、全員がスプリントゴールを自分の言葉で説明できる

## 持ち越しアイテムの扱い方

「自動で繰り越さない」は「やり途中のものを捨てて別のことをやれ」ではない。実際に判断すると、9割以上のケースで結論は「継続」になるし、それで正しい。やりかけのアイテムは「完成に一番近い在庫」であり、仕掛かり品は届くまで価値ゼロ。完成間近のものを先に終わらせるのがフロー的に最も合理的（Stop starting, start finishing）。途中のものを切って新しいものに手をつけるのは WIP を増やす悪手。

では何のために判断プロセスを挟むのか。理由は二つ。

1. **例外を見逃さないため**：レビューで方向転換が決まってそのアイテムの価値自体が消えた、着手したら想定の3倍でかいと判明した、という継続が正解でないケースが稀にある。後者は「そのまま持ち越す」のではなく、残作業を洗い出して分割・再見積もりし、新しいアイテムに仕立て直す
2. **頻度と量をシグナルとして使うため**：たまの持ち越しは正常。毎スプリント複数個持ち越しているなら、アイテムの切り方がでかすぎる・見積もりが甘い・割り込みが多い、のどれかの構造問題であり、レトロで扱うネタ。無意識の繰り越しが常態化すると、スプリントの区切りが実質なくなって「ゴールのないカンバン」になり、この問題が永遠に可視化されない

持ち越し自体は悪ではない。**無意識の持ち越しが悪**。PO が一瞬でも「これ、次スプリントでもまだ最優先？」と確認していればチェックはつく。
