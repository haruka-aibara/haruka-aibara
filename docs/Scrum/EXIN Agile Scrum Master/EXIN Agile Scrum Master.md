# EXIN Agile Scrum Master

オランダの認定機関 EXIN が提供するスクラムマスター系の認定資格。Scrum.org（PSM）や Scrum Alliance（CSM）と並ぶ選択肢のひとつで、日本語での受験・教材がある点が特徴。

## ざっくり概要

| 項目 | 内容 |
|---|---|
| 位置づけ | EXIN Agile Scrum シリーズの Master レベル（下に Foundation、別枠で Product Owner） |
| 試験形式 | 多肢選択式 40 問・クローズドブック |
| 試験時間 | 90 分 |
| 合格ライン | 65%（26/40 問） |
| 受験方法 | オンライン受験（EXIN Anywhere）または試験会場 |
| 前提資格 | 必須ではない。Foundation 相当のスクラム用語の知識が推奨 |
| 認定研修 | **認定トレーニングプロバイダでの研修と実技課題の修了が必須**（独学のみでは認定されない） |
| 日本語 | 日本語試験あり。スクラムマスター／プロダクトオーナー向けの EXIN 公式ハンドブック日本語版が無償配布 |

## 出題範囲（配点）

- アジャイルの考え方 … 10%
- スクラムマスターの役割 … 27.5%
- アジャイルな見積り・計画・モニタリングとコントロール … 32.5%
- 複雑なプロジェクト（スケーリング等） … 12.5%
- アジャイルの導入 … 17.5%

配点を見ると、スクラムのイベント・ロールの暗記よりも「見積りと計画をどう回すか」に重心がある。PSM が『スクラムガイド』の解釈を問うのに対して、ASM はアジャイル実践全般（見積り手法、スケーリング、組織導入）まで範囲が広い。

## 注意

数値・条件は 2026-09 時点で確認したもの。EXIN は試験仕様（Preparation Guide）を版ごとに更新するので、受験前に公式の最新 Preparation Guide とシラバスを必ず参照する。
