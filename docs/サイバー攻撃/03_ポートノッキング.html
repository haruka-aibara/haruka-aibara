ポートノッキング — 決めた順番でポートを叩いて開けさせる

SSH を晒したくない。でも接続元の IP が固定できない。その折衷案として出てくる仕組み。

接続元 IP で絞れないときにどうするか

SSH をインターネットに向けて開けておくと、スキャンされて総当たりログインが延々と来る。素直な対策は接続元 IP での制限だが、外出先や自宅からつなぐ場合は IP が固定できない。

そこで出てくるのが「普段はポートを閉じておき、正しい合図を出した相手にだけ開ける」というやり方。ポートノッキングでは、その合図を「決められた順番でポートに接続を試みること」で表現する。

使うときに知っておくこと

  • SSH の認証を置き換えるものではない。鍵認証はそのままに、その手前に1枚足すだけの多層防御。スキャンや総当たりの母数を減らす効果が主。
  • 合図を出す側にも道具が要る。クライアント側で決まった順にポートを叩く必要があり、手元の環境を選ぶ。
  • パケットが落ちたり順番が入れ替わると開かない。回線品質が悪いと自分が入れなくなる。

実装としては knockd が代表的。ただし新規に導入するなら、リプレイに耐える SPA のほうが選ばれる。
