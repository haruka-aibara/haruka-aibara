RFID — 触れずに読めるということは、気づかれずに読めるということ

電池のないタグが電波で応答する。便利さの根っこにある性質が、そのままリスクになる。

何が問題なのか

社員証をかざしてドアを開ける。商品タグを箱ごと一括で読み取る。改札にカードを当てる。RFID（Radio Frequency Identification）は、接触も、電池も、視認も要らずに情報をやり取りできることで普及した。

だがこの3つは、そのまま攻撃者にとっての利点でもある。持ち主に気づかれずに読める。カバンの中でも、すれ違いざまでも。

3つのリスク

  • スキミング：無断で読み取り、内容を控える。単純な ID を返すだけのタグ（古い入退室カードなど）は、これだけで複製できる。
  • 追跡：タグが常に同じ ID を返すなら、その ID を各所で拾うだけで人や物の移動が追える。持ち主が意図しない形での行動把握につながる。
  • リレー攻撃：距離の制約そのものを無効化する手口。もっとも厄介。

対策

  • 単純な ID を返すだけのタグを認証に使わない：入退室管理で古い方式のカードが残っていないかは、確認する価値がある。IC カードのように鍵を持って演算するタイプに置き換える。
  • 使わないときは電波を遮る：金属を挟んだカードケース。単純だが確実。
  • 利用者側の操作を挟む：スマートフォンの決済がロック解除や生体認証を求めるのは、勝手に応答させないため。
  • キーの節電機能を使う：車のスマートキーには、一定時間動かないと電波を止める設定が用意されていることが多い。
