# セキスペ 参考リンク

セキスペ（情報処理安全確保支援士）の勉強中に見つけた、あとで読み返したくなりそうな外部記事を置いておく場所。用語ごとの理解度は [`セキスペ_要復習リスト/`](セキスペ_要復習リスト/README.md) 側で管理していて、こっちは記事単位のブックマーク。

## 過去問

- https://www.ipa.go.jp/shiken/mondai-kaiotu/index.html — IPA 公式。問題・解答例・採点講評が無料 PDF。一次資料はここ
- https://www.sc-siken.com/ — 情報処理安全確保支援士ドットコム。午前Ⅰ・午前Ⅱが過去問道場形式（ランダム出題・正答率記録）。**科目A-1 の毎日回しはここ**
- https://www.sc-siken.com/pm_progress.html — 上の午後問題のページ。**午後をやろうと思ったらまずここを開けばよい**。問題が一覧になっていて、模範解答の PDF も見られる。解説は全問ではないが一部の設問に付いている。解説がない問題は IPA の採点講評とセットで読む

形式の注意：**令和5年度秋期から午後Ⅰ・午後Ⅱが「午後」150分・4問から2問選択に統合**された。2026年度の科目B はこの形式そのままなので、通し演習に使えるのは令和5年度秋期〜令和7年度秋期の5回分（令和7年度秋期が最後の筆記）。令和4年度以前の午後Ⅰ・午後Ⅱも問題単位の素材としては使える。
