## 復習の出し方

「説明日」は自分の言葉で説明した直近の日付。ここを起点に、忘れかけたころに出題して定着を測る。次に出す間隔は理解レベルで決める。

| 理解レベル | 次に出すまでの間隔 |
|---|---|
| 1 | 3 日 |
| 2 | 7 日 |
| 3 | 21 日 |
| 4 以上 | 60 日 |

- **説明日が空の行が最優先**。まだ一度も自分の言葉で説明していない（レベルだけ付いている行を含む）
- 出題は用語を投げるだけにする。答えを先に見せない
- 説明できたらレベルを見直して説明日を今日に更新する。言えなかった場合もレベルを下げたうえで説明日は更新する（「説明を試みた日」として扱う）

## 振り分けの決め方

小分類の境界がまたがる用語は、単体で正解を決めるより「まとまりで引けること」を優先している。以下は明示的にそう決めたもの。

- **無線 LAN 一式**（WEP / WPA / EAP / IEEE 802.1X など）→ ネットワーク方式。セキュリティ寄りの用語もここに集める
- **VPN 一式**（IPsec / IKE / SSL-VPN / PPTP など）→ セキュリティ実装技術。セキュアプロトコルとして扱う
- **PPP 一式**（PPP / PAP / CHAP / PPPoE / NCP / LCP / RAS）→ ネットワーク応用。リモートアクセスのまとまりとして扱う
- **メール送信認証**（SPF / DKIM / DMARC / SMTP-AUTH など）→ セキュリティ実装技術。プロトコル本体（SMTP / POP3 / IMAP4）は通信プロトコル
- **DNS 一式**は通信プロトコル。ただし DNSSEC だけはセキュリティ実装技術
- **HTTP 一式**は通信プロトコル。HSTS もここに含める
- 攻撃手法は情報セキュリティ、それを防ぐ側の仕組みは情報セキュリティ対策（ポートスキャンは前者、ポートノッキングは後者）
- **法律・ガイドライン・標準化**（不正アクセス禁止法、個人情報保護法、ISO/IEC の規格番号など）→ 法務。ただし ISMS 関連規格（JIS Q 27000 シリーズ）は ISMS と一緒に引きたいので情報セキュリティ管理。組織の運用ルール側（ポリシ、リスクアセスメント、CSIRT）も情報セキュリティ管理。組織が遵守を求められる基準類（PCI DSS、政府機関の統一基準、各種対策基準・ガイドライン）もここ。一方でプライバシー・個人情報保護の一式（OECD プライバシーガイドライン、プライバシーマーク、JIS Q 15001、コンプライアンスプログラム）と刑法・特別法の罪名は法務。著作権保護の技術（電子透かし、DTCP-IP）も著作権法と一緒に引きたいので法務、サイバーセキュリティ基本法・戦略・NISC も一続きで問われるのでまとめて法務
- **インシデント対応・事業継続・監査**（CSIRT、デジタルフォレンジクス、BCP / BCM、システム監査、内部統制、ISO 19011、監査基準類）→ 情報セキュリティ管理。組織として回す活動のまとまりとして扱う
- **製品・システムの評価基準**（ISO/IEC 15408、CC、JIS X 5070、TCSEC、PP / ST、EAL、CCRA など）→ セキュリティ技術評価。規格番号でも「評価するための基準」はこちらに集める
- **開発プロセス・テスト技法**（モジュール分割、テスト工程、開発モデル、CMMI など）→ ソフトウェア開発技術。ただし脆弱性を見つけるための手法（ファジング、ペネトレーションテスト）はセキュリティ技術評価
- **サービスマネジメント／ファシリティマネジメント**（SLA / OLA、JIS Q 20000、UPS や電源・空調など）→ システム構成要素ほか。セキュリティ／ネットワークどちらでもないものの受け皿として使う
