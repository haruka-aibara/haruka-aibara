# セキスペはいつ受けるか — 2026年度CBT化と2027年度試験再編の整理

（情報時点：2026年7月。新制度の詳細はまだ「案」の段階なので、受験前に必ずIPA公式で最新情報を確認すること）

## この記事が答える疑問

IPAの試験が「CBTになる」「試験区分が再編される」というニュースが立て続けに出て、何がいつ変わるのか分かりにくい。特に情報処理安全確保支援士（セキスペ／SC）を狙っている場合、**令和8年度（2026年度）に受けるのと、それ以降に受けるのとで何が違うのか**を整理する。

## 結論を先に

- **セキスペは再編後も存続する**。応用情報・高度試験が「プロフェッショナルデジタルスキル試験（仮称）」に再編される一方、セキスペは法律（情報処理の促進に関する法律）に基づく国家資格なので、試験区分としてはそのまま残る
- ただし**2027年度から試験の中身が変わる**。最大の変更は科目B（旧午後）が**記述式→多肢選択式**になり、試験時間も**150分→120分**に短縮されること
- **2026年度は「出題内容は現行のまま、実施方式だけCBT」の年**。現行形式（記述式）で受けられる最後の機会になる見込み

## 変化は2段階で起きる

### 第1段階：2026年度（令和8年度）— 実施方式の変更のみ

応用情報・高度試験・セキスペが筆記からCBT方式（テストセンターのPCで受験）に移行する。**問われる知識・技能の範囲、出題形式（多肢選択式・記述式・論述式）、出題数、試験時間はすべて現行のまま**。

| 項目 | 変更内容 |
|---|---|
| 実施方式 | 筆記 → CBT（最後の筆記は令和7年度秋期で終了済み） |
| 実施時期 | 春期・秋期 → **前期（2026年11月頃）・後期（2027年2月頃）** |
| 科目名 | 午前Ⅰ・午前Ⅱ → 科目A-1・A-2、午後 → 科目B |
| 受験日 | 実施期間中の予約枠から自分で日時・会場を選択 |
| 手数料 | 7,500円（変更なし） |

セキスペと応用情報は**前期・後期の両方で実施**される予定（年2回の受験機会は維持）。

公表済みのセキスペ（SC）のスケジュール：

| | 前期 | 後期 |
|---|---|---|
| 申込受付期間 | 2026年10月6日（火）〜10月24日（土） | 2027年1月27日（水）〜2月27日（土） |
| 科目A-1・A-2 実施期間 | 2026年10月17日（土）〜10月27日（火） | 2027年2月20日（土）〜3月2日（火） |
| 科目B 実施期間 | 2026年11月11日（水）〜11月23日（月） | 2027年3月16日（火）〜3月28日（日） |

科目Aと科目Bを**別日に受験する**方式になる点に注意。実施期間が数週間あり、その中の予約枠から自分で日時を選ぶ。裏を返せば科目Aを終えてから科目Bまで2〜3週間あるので、順番に攻略する前提で学習計画を組める。

なお申込受付期間と科目Aの実施期間は重なっている（前期なら申込は10月24日まで、科目Aは10月17日開始）。CBTは会場ごとの予約枠制で、都市部でも希望日時の席が取り合いになる可能性が指摘されているので、申込開始日に予約するつもりでいたほうがよい。**科目A-1の免除を使う場合は申込時に申請する**ため、該当するかどうかは申込開始前に確認しておく。

### 第2段階：2027年度（令和9年度）— 試験区分の再編＋セキスペの中身の変更

経産省とIPAが2026年3月31日に見直し案を公表した段階で、シラバス案・サンプル問題が2026年夏頃までに順次公開される予定。

**試験区分の再編（セキスペ以外）**：

- 応用情報＋高度試験 → **プロフェッショナルデジタルスキル試験（仮称）**に再編。「マネジメント領域」「データ・AI領域」「システム領域」の3区分
- **データマネジメント試験（仮称）**を新設
- 論述式は一旦廃止方向で、論述式に代わる高度スキル評価は2028年度以降に検討

**セキスペの変更点**：

| 項目 | 〜2026年度 | 2027年度〜（案） |
|---|---|---|
| 位置づけ | 国家資格 | 国家資格のまま存続 |
| 科目A | 現行の出題範囲体系 | 出題範囲体系を変更 |
| 科目B 出題形式 | 記述式 | **多肢選択式** |
| 科目B 試験時間 | 150分 | **120分** |
| 科目B 出題傾向 | 技術中心 | **マネジメント分野を強化** |

新制度のセキスペは**2027年度夏〜秋頃からの適用**とされている。

**経過措置**：現行の高度試験・セキスペで一部科目の免除要件を満たしている場合（例：科目A-1免除）、新試験でも一定期間、一部科目を免除することが検討されている。セキスペの科目A-2免除制度は変更しない予定。

## 2026年度に受けるか、2027年度以降に受けるか

判断軸はこのあたり。

**2026年度（現行形式のラストチャンス）に受ける理由**：

- **過去問資産がフルに使える**。長年蓄積された午後（科目B）の過去問・参考書がそのまま通用する最後の年
- 記述式で部分点を拾うスタイルが得意ならこちら
- 前期（2026年11月）・後期（2027年2月）と、現行形式で2回チャンスがある

**2027年度以降に回す理由**：

- 記述式がなくなり多肢選択式になるので、**記述の採点ブレや「書けなくて落ちる」リスクが消える**。知識勝負に寄る
- ただし初回は過去問ゼロ・対策教材未整備・シラバス案段階という不確実性を引き受けることになる
- マネジメント分野が強化されるため、技術一本で押し切る戦略は通用しにくくなる可能性がある

まとめると：**すでに現行形式で勉強を進めているなら2026年度に受け切るのが合理的**。これから着手で記述式に強い苦手意識があるなら、新形式を待つ選択肢もあるが、初回特有の情報不足リスクとトレードオフになる。
