Lambda の Python ランタイムを上げるときにやること

やることは3つ。機械に探させる、手元で動かす、dev で動かす。

何が問題なのか

AWS から「このランタイムのサポートを終了します」と通知が来る。Terraform の runtime = "python3.X" を書き換えるのは1行で済む。

困るのは、新しい Python で自分のコードが動くかどうかは、動かしてみないと分からないこと。Python は新しいバージョンで古い機能を削除することがあり、それを使っていると動かなくなる。かといって、本番でいきなり試すわけにはいかない。

1. 機械に探させる

pyright というツールは、コードを実行せずに読むだけで「存在しないものを import している行」を見つけてくれる。これを上げる先の Python の上で動かすと、新しいバージョンで消えた機能を使っている行が一覧で出る。

# 3.XX は上げる先のバージョン。--with にはコードが使うライブラリも並べる
uv run --python 3.XX --with pyright --with boto3 pyright .
lambda_function.py:1:8 - error: Import "cgi" could not be resolved

出てきた行を直す。直し方が分からなければ、エラー文をそのまま検索するか AI に渡せばよい。使っているライブラリを --with に入れ忘れると、そのライブラリも「見つからない」と出るので、それは無視してよい。

2. 手元で動かす（テスト）

1 で見つかるのは「消えた機能」だけ。実際に動くかは、動かしてみるしかない。

そこで、Lambda の関数を自動で呼び出して、結果が期待どおりか確かめる小さなプログラムを書く。これがテスト。本物の AWS には触れたくないので、moto というライブラリで偽の AWS を用意する。

たとえば「受け取ったメッセージを DynamoDB に書く」Lambda なら、テストはこうなる。

# test_lambda.py
import json
import boto3
from moto import mock_aws


@mock_aws
def test_lambda(monkeypatch):
    monkeypatch.setenv("AWS_DEFAULT_REGION", "ap-northeast-1")

    # 偽の DynamoDB にテーブルを作る
    db = boto3.client("dynamodb")
    db.create_table(
        TableName="messages",
        KeySchema=[{"AttributeName": "id", "KeyType": "HASH"}],
        AttributeDefinitions=[{"AttributeName": "id", "AttributeType": "S"}],
        BillingMode="PAY_PER_REQUEST",
    )

    # 保存しておいたイベントで、Lambda の関数を呼ぶ
    import lambda_function
    event = json.load(open("event.json"))
    lambda_function.lambda_handler(event, None)

    # DynamoDB に書かれたか確かめる
    assert db.scan(TableName="messages")["Count"] == 1

これを上げる先の Python で実行する。passed と出れば動いている。

uv run --python 3.XX --with pytest --with moto --with boto3 pytest

1本書いておけば、次にバージョンを上げるときも同じコマンドで確かめられる。pytest と moto の考え方は pytest と moto をゼロから理解する にある。

3. dev で動かす

手元では再現しない違い（Lambda に最初から入っている boto3 のバージョンなど）もあるので、最後は本物の Lambda で動かす。

  • Terraform の runtime を書き換えて、dev 環境に apply する
  • コンソールの「テスト」ボタンで、2 と同じイベントを流す
  • エラーが出なければ、本番に apply する

通知が来たら早めに始める

Lambda はサポート終了後しばらくすると、そのランタイムの関数を更新できなくなる。そうなると、問題が出たときに古いバージョンへ戻すこともできない。
