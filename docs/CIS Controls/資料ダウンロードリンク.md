# CIS Critical Security Controls 資料のダウンロードリンク

CIS Controls を参照したいとき、日本語版がどこにあるか毎回探し直すことになるのでリンクをメモしておく。

## 日本語版（v8.1）

- **CIS Critical Security Controls v8.1 日本語版**
  https://www.cisecurity.org/insights/white-papers/cis-critical-security-controls-v8-1-japanese

ホワイトペーパーとして PDF が配布されている。ダウンロードには氏名・メールアドレス等のフォーム入力が必要。

v8.1 は 18 の Control とその配下の Safeguard で構成され、各 Safeguard には組織の規模・成熟度に応じた実装グループ（IG1 / IG2 / IG3）が割り当てられている。まず IG1 を満たすところから着手する、という読み方をする。
