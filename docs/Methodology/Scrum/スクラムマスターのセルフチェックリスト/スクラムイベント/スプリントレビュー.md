# スプリントレビューのチェックリスト

タイムボックス：1か月スプリントで最大4時間（2週間なら2時間目安）。

- [ ] タイムボックス内に終わっている
- [ ] 動くインクリメントをデモしている（スライドの読み上げになっていない）
- [ ] ステークホルダーが実際に参加し、フィードバックが出ている
- [ ] 出たフィードバックがプロダクトバックログに反映されている
- [ ] 承認会・進捗報告会ではなく、「次に何を作るか」を検討する場になっている

レビューが機能していないと、本来ここで消化されるべきプロダクトの話題がレトロスペクティブに流れ込む。[レトロスペクティブのチェックリスト](スプリントレトロスペクティブ.md)の「プロダクトの話」の項も参照。
