# 理解レベルの定義

学習メモで「この用語は理解レベル 2」のように自己申告するための共通スケール。特定の教材や資格に紐づけず、どの勉強資料でも同じ物差しを使う。

| レベル | 名称 | 状態 | 例（Docker の場合） |
|---|---|---|---|
| 0 | 未認知 | 技術/ツールの存在を知らない。技術領域についての知識がない | Docker やコンテナ技術の存在を知らない |
| 1 | 基本的な認識 | 名前のみ認識、詳細な理解はない。機能や動作原理を説明できない | Docker という名前は知っているが、コンテナ技術の詳細や動作原理を理解していない |
| 2 | 基本的な理解 | 技術/ツールの目的と基本概念を理解している。基本的な用語や概念を説明できる | Docker の目的と基本的なコンテナ技術の概念を理解し、説明できる |
| 3 | 理論的知識 | 体系的な学習知識はあるが、実践経験は限定的。基本的な操作手順と概念を理解している | Docker の基本的な操作手順と概念を理解しているが、実践経験は限定的 |
| 4 | 実践的知識 | 実践経験があり、基本的な問題を解決できる。基本的な業務状況で活用できる | 基本的な Docker 環境の構築と問題解決ができる |
| 5 | 専門的な使用 | 専門的な業務で効果的に活用できる。複雑な問題の解決と最適化ができる | 本番環境での Docker 環境の構築、運用、最適化ができる |
| 6 | エキスパートレベル | 高度なアーキテクチャを設計できる。技術的なガイダンスやコミュニティへの貢献ができる | Docker の開発に貢献したり、高度な Docker プラグインを開発できる |

## 使い方

学習メモは「用語 / ページ / 理解レベル / 備考」のテーブルで管理し、理解レベル列に数字を入れる。

| 用語 | ページ | 理解レベル | 備考 |
|---|---|---|---|
| VXLAN | p.525 | 1 | |
| TCP/IP | p.497 | 4 | |

レベルが変わったら `0→1` のように矢印で書き、変化を残す。下がることもある（一度理解したつもりでも説明できなくなっていたら下げる）。

| 用語 | ページ | 理解レベル | 備考 |
|---|---|---|---|
| automatic fortification | p.65 | 0→1 | |
