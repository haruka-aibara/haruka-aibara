# ISO/IEC 27002 の解説サイトのリンク

ISO/IEC 27001 の附属書 A は管理策の名前が並んでいるだけで、「で、具体的に何をやれば満たしたことになるのか」は書かれていない。その実施の手引きにあたるのが ISO/IEC 27002 だが、規格本体は購入しないと読めない。手元で管理策の中身を確認したいときに毎回探し直すことになるので、日本語の解説サイトをメモしておく。

## リンク

- **ISMS ガイド（ISO/IEC 27001・27002 の解説）**
  https://isms-guide.com/

## 何を調べるときに開くか

- 27001 = ISMS の要求事項。認証審査で見られるのはこちら
- 27002 = 管理策の実施ガイド。附属書 A の各項目について、目的と実施の手引きが書かれている

「附属書 A のこの項目、何をすれば満たしたことになるのか」を調べる場面が 27002 の出番。

2022 年版で管理策は **93 個・4 テーマ（組織的 / 人的 / 物理的 / 技術的）** に再編された。旧版（2013 年版）は 114 個・14 章で章立てが違うので、古い資料や社内文書を見るときは版を確認する。

規格の系譜・27001 と 27002 の役割分担・認証審査の流れは [ISMSと関連規格をゼロから理解する](./ISMSと関連規格をゼロから理解する.html) にまとめてある。
