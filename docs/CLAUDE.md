# Claude Code 向けメモ

このリポジトリの共通作業ルールは `AGENTS.md` を参照してください。Claude Code 固有ではない指示・判断軸・既存コンテンツ情報は、他のコーディングエージェントからも読めるように `AGENTS.md` を正として管理します。

## メモリ運用

このリポジトリは VSCode devcontainer で動いているため、`~/.claude/` 配下のメモリファイルはコンテナ再起動・別PC起動で消える可能性があります。**会話をまたいで残すべき情報は `~/.claude/` や `MEMORY.md` ではなく、リポジトリ内のファイルに書いてください。**

- 全エージェントに共通する情報: `AGENTS.md` に追記
- Claude Code だけに必要な情報: この `CLAUDE.md` に最小限だけ追記
