IP ヘッダの構成

パケットキャプチャの画面に並ぶフィールド。全部覚える必要はないが、調査で見る場所は決まっている。

調査で実際に見るフィールドは限られる

IPv4 ヘッダは 20 バイト（オプションなしの場合）に 13 個のフィールドが詰まっている。ただし障害調査やセキュリティ調査で目を向けるのは、そのうちの数個。

TTL は「時間」ではなくホップ数

Time To Live という名前だが、実際に減るのは秒数ではなくルータを通過した回数。0 になったパケットはそのルータが破棄し、送信元に ICMP の「時間超過」を返す。

この性質をそのまま使ったのが traceroute。TTL=1 のパケットを送ると 1 台目のルータが破棄してエラーを返してくるので、その送信元 IP から 1 台目が分かる。次に TTL=2 で 2 台目——と繰り返して経路を割り出す。
