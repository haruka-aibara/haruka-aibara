POP before SMTP

昔の SMTP には認証がなかった。「さっき POP でログインできた人なら本人だろう」という間に合わせで送信者を確かめていた時代の方式。

受信の認証を、送信の許可に流用する

SMTP はもともと認証の仕組みを持たず、誰でも送信サーバにメールを投げられた。これでは迷惑メールの踏み台にされてしまう。かといってプロトコルを変えるのは大ごと。

そこで使われたのが POP before SMTP。POP3 には認証があることを利用して、「POP3 でログインに成功した IP アドレスからの SMTP 送信を、一定時間だけ許可する」という運用でしのいだ。

現在は使わない。SMTP 自体に認証を追加した SMTP-AUTH が標準になり、POP before SMTP は「SMTP に認証がなかった時代の回避策」として名前だけ残っている。
