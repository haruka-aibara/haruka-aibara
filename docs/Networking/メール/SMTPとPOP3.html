SMTP と POP3

メールは 1 本のプロトコルで相手に届くのではない。「送る・運ぶ」と「受け取りに行く」は別のプロトコルの仕事。

押し出す SMTP、取りに行く POP3

メールが相手の端末に「直接」届くことはない。送信者が送ったメールはいったん受信者側のメールサーバの私書箱（メールボックス）に溜まり、受信者が好きなタイミングで取りに行く。相手の端末が電源オフでも送れるのはこの構造のおかげ。

この過程で使うプロトコルが 2 系統に分かれる。

  • SMTP — メールを送信・転送する。端末 → 送信サーバ、送信サーバ → 受信サーバの両方で使われる（押し出す方向）
  • POP3 — メールボックスに溜まったメールを端末が取りに行く。基本動作は「ダウンロードしてサーバから削除」

POP3 は「ダウンロードして手元管理」なので、複数端末で同じメールボックスを見ると破綻する。その問題を解決するのが IMAP4。
