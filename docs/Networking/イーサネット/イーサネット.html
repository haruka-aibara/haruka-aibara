イーサネット

「同じ LAN の中で、隣の機器までデータを渡す」だけを担当するルール。IP より下で動いている。

IP アドレスだけでは 1 ミリも動かない

IP アドレスは「世界のどこにいるか」を表す住所だが、実際にケーブルや電波にビットを流すときに使われているのは IP アドレスではない。同じネットワーク内で「隣のどの機器に渡すか」を決める仕組みが別に要る。それがイーサネット。

有線 LAN でほぼ独占的に使われており、機器には製造時に MAC アドレス（48 ビット）が焼かれている。イーサネットはこの MAC アドレス宛てにフレームを届ける。

「届けたか確認しない」という割り切り

イーサネットは確認応答も再送もしない。壊れたフレームは黙って捨てる。信頼性は TCP など上の層に任せる、という分業になっている。

また、宛先 MAC がすべて FF:FF:FF:FF:FF:FF のフレームはブロードキャストとして同じネットワークの全員に届く。相手の IP は分かるが MAC が分からないときに使う ARP がこの仕組みを使っている。
