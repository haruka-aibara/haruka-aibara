IPv6 の表記方法

128 ビットをそのまま書くと長すぎる。省略ルールを知らないと、同じアドレスが別物に見える。

省略前と省略後が同じものだと分かる必要がある

設定ファイルには 2001:db8::1 と書いてあり、ログには 2001:0db8:0000:0000:0000:0000:0000:0001 と出ている。これが同じアドレスだと分からないと、突き合わせができない。

IPv6 は 128 ビットを 16 ビットずつ 8 ブロックに区切り、コロンでつないだ 16 進数で書く。そのうえで 2 つの省略ルールがある。

実際に書くときのルール

  • 16 進数は小文字で書く — 2001:DB8::1 ではなく 2001:db8::1（RFC 5952 の推奨）
  • 0 が 1 ブロックだけのときは :: にしない — 2001:db8:0:1::1 のように書く。1 ブロックなら 0 のほうが短いか同等
  • 連続する 0 が複数箇所あるときは、長いほうを :: にする
  • URL に書くときは角括弧で囲む — http://[2001:db8::1]:8080/。囲まないと : がポート番号の区切りと区別できない

プレフィックス長は IPv4 と同じ書き方

2001:db8:1234::/48 のように、末尾に / とビット数を書く。IPv4 の CIDR 表記と同じ考え方で、先頭から何ビットがネットワーク部かを表す。IPv6 では /64 が 1 つのネットワーク（サブネット）の標準的な単位になる。
