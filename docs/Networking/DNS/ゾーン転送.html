ゾーン転送

権威サーバが 1 台きりだと、その 1 台が落ちた瞬間にドメインごと世界から見えなくなる。台数を増やせば、今度は中身の同期が要る。

プライマリの原本をセカンダリに複製する

権威サーバは必ず複数台で運用する。原本（ゾーンファイル）を編集するのはプライマリ 1 台だけにして、セカンダリはプライマリからゾーンデータを丸ごと複製する。この複製の仕組みがゾーン転送。

全レコードを送る AXFR（完全転送）と、前回からの差分だけ送る IXFR（差分転送）がある。データ量が多く確実に届く必要があるため、通常の名前解決（UDP）と違って TCP の 53 番を使う。

転送要求元を制限しないと、ゾーンの全レコードを誰でも入手できる。ゾーン転送は「全部ください」に全部答える仕組みなので、無制限だと攻撃者が内部のホスト名・サーバ構成を一覧で手に入れる偵察手段になる。セカンダリの IP アドレスだけに許可するのが基本。
