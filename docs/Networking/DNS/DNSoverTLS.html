DNS over TLS

Web は HTTPS で暗号化した。でもその直前に飛ぶ DNS の問い合わせは平文のまま。「どのサイトを見ようとしているか」は経路上から丸見えだった。

通信内容は隠せても、行き先は漏れる

従来の DNS は UDP 53 番ポートの平文。端末からキャッシュサーバへの問い合わせは、公衆 Wi-Fi の管理者や経路上の第三者から盗聴も改ざんもし放題だった。HTTPS でページの中身を守っても、「この端末が example.jp を引いた」という行動履歴は筒抜けになる。

このスタブリゾルバ〜キャッシュサーバ間を TLS で包んだのが DNS over TLS（DoT）。TCP 853 番ポートを使う。

同じ目的で、DNS を HTTPS（443 番）に載せる DNS over HTTPS（DoH）もある。DoT は専用ポートなのでネットワーク管理者から「DNS の暗号化通信」と識別できるのに対し、DoH は普通の Web 通信に紛れる、という運用上の違いがある。
