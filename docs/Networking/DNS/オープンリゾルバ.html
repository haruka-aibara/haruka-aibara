オープンリゾルバ

誰の質問にも答える親切なキャッシュサーバは、DDoS の踏み台として最高の性能を発揮してしまう。

「誰にでも答える」がなぜ問題か

キャッシュサーバ（フルサービスリゾルバ）は本来、自組織や契約者の端末のためのもの。ところがアクセス制限をかけずにインターネット全体からの再帰的問い合わせを受け付けている状態——これがオープンリゾルバ。設定ミスや家庭用ルータの初期設定でこうなっていることが多い。

DNS は UDP で動き、小さな質問に大きな応答を返す。この2つの性質が悪用の材料になる。

対策は「答える相手を絞る」だけ

キャッシュサーバは、再帰的問い合わせを受け付ける範囲を自組織・契約者の IP アドレスに限定する。外に公開する必要があるのは権威サーバであって、キャッシュサーバではない——この2つの役割を同居させないことが出発点になる。踏み台以外にも、誰でも問い合わせられる状態はキャッシュポイズニング（カミンスキーアタック）を仕掛けやすくする。
