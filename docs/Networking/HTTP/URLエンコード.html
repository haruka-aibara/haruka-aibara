URL エンコード

URL に書ける文字は限られている。日本語も、スペースも、「&」も、そのままでは置けない。置けない文字を置ける形に変換する決まりごと。

「区切り記号」と「データ」がぶつかる

URL では ? & = / などの記号が構造の区切りとして意味を持っている。たとえば検索キーワードとして「A&B」を送りたいとき、& をそのまま書くと「パラメータの区切り」と解釈されてデータが途切れる。日本語などの非 ASCII 文字は、そもそも URL の文字集合に入っていない。

そこで、そのまま書けない文字は UTF-8 のバイト列に直し、1 バイトずつ %XX（16 進数 2 桁）で表記する。これが URL エンコード（パーセントエンコーディング）。
