Cookie の属性

セッション ID の入った Cookie が盗まれれば、パスワードなしで本人になりすませる。属性は「どこへ・誰に・いつまで」送るかを絞る防御線。

Cookie は黙っていると出歩きすぎる

Cookie はサーバが Set-Cookie ヘッダで置いていき、以後ブラウザが同じサイトへのリクエストに自動で添える。この「自動で添える」が便利さの源泉であり弱点でもある。何も指定しないと、平文の HTTP でも送るし、ページ内の JavaScript から読めるし、他サイト発のリクエストにも付いていく。属性はこの範囲を絞るためにある。

属性の一覧

属性絞るもの意味
Secure経路HTTPS のときだけ送る
HttpOnly読み手JavaScript（document.cookie）から読めなくする
SameSite発信元他サイト起点のリクエストに付けるかどうか（Strict / Lax / None）。CSRF の緩和策
Domain / Path宛先どのドメイン・パスへのリクエストに付けるか
Expires / Max-Age期間いつまで保持するか。指定なしはブラウザを閉じるまでのセッション Cookie
