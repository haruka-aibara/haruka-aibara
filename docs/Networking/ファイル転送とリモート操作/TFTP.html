TFTP

機能を削れるだけ削ったファイル転送。ROM に焼けるほど小さいことが取り柄。

OS がまだ無い機器にファイルを渡したい

ディスクを持たない端末をネットワークから起動する、ルータやスイッチにファームウェアを流し込む、IP 電話が設定ファイルを取りに行く。こういう場面では、まだ TCP スタックも認証の仕組みも動いていない状態でファイルを取ってくる必要がある。TFTP はそのために機能を削ぎ落とした転送方式で、UDP の 69 番を使い、認証がなく、get と put しかできない（一覧表示も削除もない）。
