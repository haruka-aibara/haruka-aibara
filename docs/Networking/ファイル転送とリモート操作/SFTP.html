SFTP

FTP を暗号化したものではない。SSH の上で動く、まったく別のファイル転送。

SSH がつながるなら、それだけで転送できる

FTP はコマンドもパスワードもファイルも平文で流れる。じゃあ暗号化しようとなったとき、SFTP が採った手はシンプルで、すでにある SSH の通り道に相乗りするというもの。サーバ側で SSH が動いていればたいてい追加設定なしで使え、開けるポートは 22 番の 1 本だけ。FTP のようにデータ用の別コネクションを張らないので、NAT やファイアウォールで悩む場面もない。

使い方は FTP とだいたい同じ

sftp user@example.com で入り、ls / cd / get / put で操作する。1 ファイルをコピーするだけなら同じ SSH 上で動く scp もある。
