インターネット VPN と IP-VPN

拠点間を安く繋ぐか、品質を金で買うか。VPN の2系統。

何が問題なのか

本社と支社を繋ぎたい。専用線を引けば確実だが、距離と帯域に比例して月額が跳ね上がるうえ、拠点が増えるたびに回線が増える。かといって普通にインターネットで繋ぐと、経路上のどこかで盗聴・改ざんされうる。

共用の回線を使いながら、専用線のように扱いたい——これが VPN（Virtual Private Network）。実現の仕方が2系統ある。

インターネット VPN

既存のインターネット回線をそのまま使う。経路は不特定多数と共用なので、安全性を担保するのは自分たちで張る暗号化トンネル（ほとんどは IPsec）だけ。

  • 安い。すでに引いてあるインターネット回線で足りる
  • 経路を選べない。遅延も帯域も保証されない（混んだら遅い）

IP-VPN

通信事業者が持つ閉域 IP 網を使う。インターネットには繋がっていない網の中で、契約者ごとにトラフィックを分ける。分離には MPLS のラベルが使われる——パケットにラベルを付けて、同じ網でも別々の経路表で転送する。

  • 遅延・帯域に SLA が付く。品質を契約で買える
  • 高い。拠点ごとに事業者との回線契約が要る
  • 網の中は暗号化されない

選ぶときの基準

  • 止まると業務が止まる基幹系なら IP-VPN：SLA を買う価値がある。逆に、遅延に鈍い業務なら払う意味は薄い
  • 拠点が小さい・数が多いならインターネット VPN：回線を選ばず、光でもモバイルでも張れる
  • 併用も普通：主回線を IP-VPN、バックアップをインターネット VPN にする構成はよくある
