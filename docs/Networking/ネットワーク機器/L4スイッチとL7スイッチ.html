L4 スイッチと L7 スイッチ

「どのサーバに振り分けるか」を、何を見て決めるか。負荷分散装置の 2 つの立ち位置。

サーバを増やしたら、振り分ける人が必要になる

Web サーバ 1 台では処理しきれなくなったので 3 台に増やした。しかし利用者は 1 つの URL にアクセスしてくる。誰かが手前に立って、リクエストを 3 台に配る必要がある。これが負荷分散装置（ロードバランサ）で、判断材料をどこまで見るかで L4 と L7 に分かれる。

使い分け

L4 スイッチL7 スイッチ
判断材料IP アドレス・ポート番号URL・Host ヘッダ・Cookie など
できること台数分の負荷分散、死活監視パスによる振り分け、セッション固定、TLS 終端、WAF 連携
処理コスト低い高い（中身を解析するため）

AWS でいえば NLB が L4、ALB が L7 にあたる。単純に台数を並べたいだけなら NLB、マイクロサービスをパスで振り分けたり WAF を挟んだりするなら ALB、という選択になる。
